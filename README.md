# norah-portfolio

Portfolio editorial de Norah Martín — edición "Archivo Nº01".

Sitio de una sola página, sin dependencias ni build. Solo HTML + CSS + vanilla JS.

## Detalles de diseño

- **Tipografía**: Instrument Serif (display) · JetBrains Mono (metadata)
- **Paleta**: carbón cálido `#0A0908` · crema `#EDE5D5` · cadmio `#EE5E39`
- **Motion**: reveal del nombre por letras, marquee infinito, cursor custom con blend-mode, reloj CEST en vivo, progress bar, hover-expand en proyectos
- **Grano**: overlay SVG (feTurbulence) con blend mode overlay

## Deploy

Servido vía GitHub Pages desde `main` → `/` (root).
